# elintir-site

Статичний сайт-візитка ТОВ «ЕЛІНТІР» — https://elintir.com

Публічний репозиторій навмисно: GitHub Pages не обслуговує приватні репо на
безкоштовному плані. Тут лежать лендінг і публічна дослідницька візуалізація
`/rassvet/`; код основного продукту — у приватному `elintir_mapper`.

`/rassvet/` читає лише статичні файли з цього репозиторію. GitHub Actions
оновлює орбітальні GP і історію тривог раз на дві години. Для запуску потрібен
репозиторний секрет `ALERTS_API_TOKEN`; його не можна записувати у файли сайту
або параметри URL. Якщо джерело недоступне, Action завершується помилкою і
GitHub Pages продовжує віддавати попередній знімок із його датою. Архів GP,
отриманий за спеціальним запитом, автоматично не оновлюється: для нових днів
зберігаються окремі публічні добові GP-знімки.

Для дослідників доступні [JSON-файли та опис формату](rassvet/data/README.md),
а на сторінці — CSV проходів для введених координат і порога видимості.

## Склад

| Файл | Призначення |
|------|-------------|
| `index.html` | Уся сторінка: розмітка + CSS в одному файлі, без JS і зовнішніх залежностей |
| `404.html` | Редірект на головну |
| `CNAME` | Кастомний домен `elintir.com` (не видаляти — Pages читає саме його) |
| `assets/elintir-hero.png` | Картинка для `og:image` |
| `.nojekyll` | Вимикає обробку Jekyll — файли віддаються як є |

## Деплой

Push у `main` → GitHub Pages підхоплює автоматично за хвилину-дві.

```bash
git add -A && git commit -m "site: ..." && git push
```

## DNS

Apex і `www` вказують на IP GitHub Pages (`185.199.108-111.153`). Ці записи
жити мають незалежно від репозиторію — при переїзді сайту між репо DNS
чіпати не треба, достатньо CNAME-файлу і налаштування Pages у новому репо.

## Локальний перегляд

```bash
python -m http.server 8137
```
