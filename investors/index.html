ELINTIR / Інвесторам

Одна радіоплатформа. Кілька продуктів.

Ми створюємо SDR-системи для розвідки та зв’язку. Цінність накопичується в алгоритмах обробки сигналу, реалізації в FPGA та даних для наступних ітерацій.

02 / Основа зростання

Одна платформа. Повторне використання розробок.

Когерентне приймання, обробка сигналу у FPGA та застосунок оператора працюють для кількох продуктових напрямів. Виміри та збережені дані роблять кожний цикл перевірки ціннішим.

Перевірка
