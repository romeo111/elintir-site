# ELINTIR — логотип сайту

Знак: **Δ∕λ по діагоналі у п'ятикутнику** — Δ вгорі ліворуч, риска-промінь по
діагоналі, λ внизу праворуч. Це не орнамент, а схема станції:

- **П'ятикутник + 5 точок у вершинах** — 5-елементна кільцева антенна решітка
  (UCA) KrakenSDR, елементи що 72°.
- **Δ∕λ** — рознос елементів до довжини хвилі: те саме d/λ, що
  `apply_doa_spacing` перераховує на кожен ретюн; зіпсоване значення фабрикує
  пеленг 0.0° — задокументований польовий інцидент. Риска дробу — заразом
  промінь пеленга через решітку.
- **Слоган**: `ML SDR MAPPER`.

Історія: v1 — ψ у центрі (заокруглений ψ зчитувався як тризуб), v2 —
вертикальний дріб Δ/λ (виглядав втиснуто), v3 (поточна, 2026-08-22) —
діагональна композиція зі зменшеними елементами; рішення власника.

## Система розмірів

- **≥ 64 px** — повний знак (діагональний Δ∕λ): лок-апи, хіро, PWA 192/512.
- **< 64 px** — спрощений знак `elintir-favicon-small.svg` (п'ятикутник +
  суцільний Δ): шапки сайту й вікі (34–46 px), favicon 16/32/48. Дрібні
  елементи повного знака на цих розмірах зливаються — перевірено попіксельно.

## Кольори

Палітра лого — **чорний + темно-зелений** (рішення власника, 2026-08-22).
Токени консолі (`_ui/_web_interface/assets/style.css`) не змінюються.

| Роль | Значення |
|------|----------|
| Темно-зелений (знак, назва, слоган на темному) | `#4f7f28` |
| Глибокий зелений (рамка плитки favicon) | `#2f4b19` |
| Чорний (плитка favicon, тло) | `#0a0c08` |
| Чорнило на світлому (каркас, трафарет) | `#0d0f0a` |
| Темно-зелений на світлому (Δ∕λ, точки) | `#3e6b1f` |

Шрифти — ті самі токени, що в UI: `Montserrat` (назва/слоган), `JetBrains Mono`
для технічних підписів; шрифти в SVG не зашиті, на сайті їх треба підключити
(або змиритися з фолбеком, він тримається).

## Використання

```html
<!-- favicon -->
<link rel="icon" type="image/svg+xml" href="/static/elintir-favicon-small.svg">

<!-- шапка сайту -->
<img src="/static/elintir-logo-horizontal.svg" alt="ELINTIR — ML SDR MAPPER" height="44">
```

Не розтягувати, не перефарбовувати поза таблицею кольорів, не класти на
строкате тло; на дуже темному нейтральному тлі знак лишається темно-зеленим —
це свідомий «стелс»-контраст.

## Згенеровані растри (2026-08-22)

- `_ui/_web_interface/assets/icon-192.png`, `icon-512.png` — PWA-іконки з
  `elintir-favicon.svg` (повний знак).
- `_ui/_web_interface/assets/favicon.ico` і `_superspeed/static/favicon.ico` —
  мультирозмірний ICO 16/32/48 з `elintir-favicon-small.svg`.
- Пайплайн: headless Chromium растеризує SVG (майстер ~1200 px, прозоре тло,
  кроп за альфою) → Pillow LANCZOS-даунскейл → PNG-in-ICO. Повторити можна
  будь-яким SVG-растеризатором — головне зберегти пари «розмір ↔ джерело» вище.
- Шапки й favicon сторінок: хмара (`_cloud_mvp/app.py` дашборд,
  `auth.py` логін/відмова) і вікі (`docs/wiki/elintir_wiki.html`) несуть
  спрощений знак інлайном (data-URI/inline SVG, без статичних файлів); вікі
  перемикає кольори знака темою через `--logo-frame` / `--logo-accent`.
